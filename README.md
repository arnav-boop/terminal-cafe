# terminal cafe

 terminal cafe is a python based cafe game, where you upgrade shop and manage customers, that runs entirely in your terminal! survive 7 days without your rep hitting  zero or going bankrupt!!

## features
 - manage stock: cook drinks and edibles, and manage spoilt food
 - upgrade your store: spend money to buy cooks and restock
 - random events: face random surprises like food critics and rush hours
 - basic sounds
- and most importantly, coookkk as fast as you can

## how to run it
1. download terminalcafe.exe
2. double click the file to launch the game in a windows terminal
3. in the same folder itll save highscore.txt to save your scores

## controls
- press the alphabet letters to cook your customers orders
- spacebar to pause and resume a game
- q to quit the game
- survive all 7 days to win, game ends when you go bankrupt or rep hits 0
- auto-chef might be gone for a break, if a customer's still waiting, cook!

## requirements
1. python 3.11
2. windows
